# Family Arcade

A menu of our family's browser games. Open `index.html` (or the GitHub Pages link) and pick a game.

## Games
| Game | Folder |
|---|---|
| Mathlings | `games/mathlings/` |
| Math Hopper | `games/math-hopper/` |
| Math Hopper 3D | `games/math-hopper-3d/` |

## Adding a game
1. Make a new folder under `games/` and save the game as `index.html` inside it (plus any files it needs).
2. Open the main `index.html` and add an entry to the `GAMES` list near the bottom.
3. Commit and push. GitHub Pages republishes the site automatically, usually within a minute.

## Updating a game
Replace that game's `games/<name>/index.html` with the new version, then commit and push.
